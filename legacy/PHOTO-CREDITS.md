## Image Optimization Tips

To keep images under 150 KB:

1. **Resize before uploading**
   - Maximum width: 1200px for desktop
   - Maximum width: 800px for mobile

2. **Compress images**
   - Use tools like TinyPNG (https://tinypng.com/)
   - Or Squoosh (https://squoosh.app/)
   - Aim for 70-80% quality

3. **Use WebP format**
   - WebP offers better compression than JPEG
   - Provide JPEG fallback for older browsers
   - Example: `<picture><source srcset="image.webp" type="image/webp"><img src="image.jpg" ...></picture>`

4. **Remove metadata**
   - Use image compression tools that strip EXIF data
   - Reduces file size and protects privacy
